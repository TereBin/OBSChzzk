# OBSChzzk 통합 설치 1.1.8

Windows 10/11 x64용 온라인 설치 프로그램입니다. .NET Framework 4.5 이상과 인터넷 연결이 필요합니다.

## 다운로드

- [최신 통합 설치 파일 다운로드](https://github.com/TereBin/OBSChzzk/releases/latest/download/OBSChzzk-1.1.8-windows-x64-setup.exe)
- [릴리스 및 SHA-256 체크섬](https://github.com/TereBin/OBSChzzk/releases/latest)

## 사용

1. OBS와 치지직 리모컨을 종료하고 다운로드한 `OBSChzzk-1.1.8-windows-x64-setup.exe`를 실행합니다.
2. 설명을 읽고 원하는 플러그인의 체크박스만 선택합니다. 기본값은 모두 선택입니다.
3. `선택한 플러그인 설치`를 누릅니다.
4. 완료 후 OBS를 직접 실행하고 선택한 플러그인을 설정합니다.
5. 완료 화면에 표시된 선택한 플러그인의 사용 설명서 링크를 클릭하면 기본 브라우저에서 해당 배포 저장소의 README가 열립니다.
6. Event를 설치했다면 확장 프로그램 등록 안내와 실제 폴더 경로가 추가로 표시됩니다. `확장 프로그램 폴더 열기`를 클릭해 탐색기로 이동한 후 Chrome/Edge 확장 프로그램의 개발자 모드에서 해당 폴더를 압축해제된 확장 프로그램으로 로드하세요. 이미 등록했다면 브라우저에서 새로고침합니다.

| 플러그인 | 역할 |
| --- | --- |
| Event | 치지직 신규 팔로우를 화면·소리로 알림 |
| LiveEditor | OBS에서 치지직 방송 제목·카테고리·태그 수정 |
| Ping | 방송 시작 시 Discord 알림 및 X 작성창 열기 |

체크하지 않은 플러그인은 다운로드·설치하지 않습니다. 이미 설치된 플러그인의 체크를 해제해도 제거하지 않습니다.

각 플러그인 이름 아래에 개별 진행 상태가 표시됩니다: `대기 중 → 릴리스 확인 중 → 다운로드·검증 중 → 설치 대기 → 설치 중 → 완료`. 선택하지 않은 항목은 `선택 안 함`, 실패한 항목은 `실패`, 이후 진행하지 못한 항목은 `중단됨`으로 구분합니다. 설치 완료 후에도 각 항목의 완료 상태와 README 링크를 함께 볼 수 있습니다. 다운로드와 설치는 순서대로 진행합니다.

## 업데이트

실행 시 설치 버전과 GitHub 최신 정식 버전을 자동으로 확인해 함께 표시합니다. 별도 확인 버튼은 없습니다. 설치 버전은 OBS 폴더의 DLL에서 제품 버전(없으면 파일 버전)을 읽습니다. 이전 이름의 LiveEditor DLL도 확인합니다.

비교 결과는 `업데이트 가능`, `최신 버전`, `설치 버전이 더 높음`, `미설치`로 표시합니다. 파일에 버전 정보가 없거나 비교할 수 없는 형식이면 `버전 비교 불가`로 표시합니다. 최신 버전 조회에 실패해도 설치 버전은 표시합니다. 최신 조회에는 인터넷이 필요하며, 버전 확인 자체는 OBS 실행 중에도 가능합니다.

실행 중 확인한 최신 릴리스 정보를 재사용해 설치 직전의 중복 API 요청을 줄입니다. 처음 조회하지 못한 항목은 설치할 때 다시 조회합니다. API가 403 또는 429를 반환하면 공식 GitHub 최신 릴리스 페이지와 첨부된 `SHA256SUMS.txt`로 확인합니다. 초안과 사전 릴리스는 제외합니다. 장시간 창을 열어 두었다면 다시 실행해서 최신 정보를 확인하세요.

공식 저장소에서 해당 플러그인 이름으로 시작하고 `setup.exe`로 끝나는 EXE 하나를 선택합니다(대소문자 무시). Ping의 `OBSChzzkPing-Setup.exe`도 지원합니다. 적합한 EXE가 없거나 여러 개면 중단합니다.

선택한 파일을 모두 다운로드하고 SHA-256을 검증한 후 공식 설치 프로그램을 순서대로 무인 실행합니다. API 경로는 digest와 파일 크기를, 페이지 대체 경로는 공식 체크섬 파일의 해시를 사용합니다. 조회·다운로드·검증이 실패하면 이전 파일로 대신 설치하지 않습니다.

플러그인 업데이트 때마다 통합 EXE를 다시 빌드할 필요가 없습니다. 저장소, 파일 이름 규칙, 원본 설치 프로그램의 명령줄 방식이 바뀌면 통합 프로그램 수정이 필요합니다. 백그라운드 자동 업데이트는 없으며 새 버전을 받으려면 통합 프로그램을 다시 실행합니다.

설치된 버전과 비교하지 않고 최신 정식 버전을 재설치합니다. 시험판·개발 버전을 사용 중이라면 정식 버전으로 바뀔 수 있습니다.

## 제약 및 실패 처리

원본 Event 설치 프로그램에 맞춰 32비트 HKLM 레지스트리의 OBS Studio 제거 경로, 이후 Program Files의 obs-studio를 사용합니다. 포터블 OBS와 수동 경로 선택은 지원하지 않습니다. Ping에는 같은 OBS 경로를 `/OBSPATH`로 전달합니다.

OBS 실행 중 설치를 차단합니다. 설치 중 OBS를 실행하지 마세요. 일부 단계가 실패해도 완료된 설치는 유지됩니다. 전체 롤백은 제공하지 않으며 재실행할 수 있습니다. 원본 설치 로그와 릴리스 URL·버전·해시는 `%LOCALAPPDATA%\OBSChzzk\Logs`에 저장합니다.

Event 확장 등록/새로고침, LiveEditor 로그인, Ping 채널·알림 설정은 사용자가 완료해야 합니다. 제거는 Windows 설치된 앱에서 각각 진행합니다.

## 빌드와 검사

Windows 기본 .NET Framework 컴파일러를 사용하며 빌드에는 네트워크가 필요하지 않습니다.

```powershell
./build.ps1
./test.ps1
# 조회·다운로드·해시 검사만 수행하며 실제 설치하지 않습니다.
./test.ps1 -Network
```

배포 파일은 `dist/OBSChzzk-1.1.8-windows-x64-setup.exe`와 `dist/SHA256SUMS.txt`입니다. 이전 1.0.0 EXE는 고정 버전이므로 신규 배포에 사용하지 마세요. EXE는 코드 서명되지 않았습니다.
