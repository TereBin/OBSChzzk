# OBSChzzk 통합 설치

OBSChzzkEvent, OBSChzzkLiveEditor, OBSChzzkPing을 원하는 조합으로 설치하고 업데이트할 수 있는 Windows용 프로그램입니다.
이 저장소에서 **설치 파일과 소스 코드**를 함께 제공합니다.

## 주요 기능

- 체크박스로 원하는 플러그인만 선택 설치
- 플러그인별 역할 설명과 설치된 버전 표시
- 최신 정식 버전 및 업데이트 가능 여부 자동 확인
- 공식 배포 저장소에서 설치 파일 다운로드 및 SHA-256 무결성 검사
- 플러그인별 다운로드·설치 진행 상태 표시
- 설치 완료 후 각 플러그인의 사용 설명서 바로 가기
- Event 브라우저 확장 프로그램의 웹 스토어 설치 링크와 기존 설치본 전환 안내
- 통합 설치 프로그램 자체의 새 버전 알림과 교체·재실행

## 설치할 수 있는 플러그인

| 플러그인 | 주요 역할 | 사용 설명서 |
| --- | --- | --- |
| OBSChzzkEvent | 치지직 신규 팔로우를 화면과 소리로 알림 | [Event 사용 설명서](https://github.com/TereBin/OBSChzzkEvent-Releases#readme) |
| OBSChzzkLiveEditor | OBS 도크에서 치지직 방송 제목·카테고리·태그 수정 | [LiveEditor 사용 설명서](https://github.com/TereBin/OBSChzzkLiveEditor-Releases#readme) |
| OBSChzzkPing | 방송 시작 시 Discord 알림 전송 및 X 작성 화면 열기 | [Ping 사용 설명서](https://github.com/TereBin/OBSChzzkPing-Release#readme) |

**Event는 설치 후 Chrome 또는 Edge에 브라우저 확장 프로그램을 웹 스토어에서 별도로 설치해야 합니다.**
LiveEditor의 로그인과 Ping의 채널·알림 설정도 설치 후 진행해 주세요.

## 요구 사항

- Windows 10 또는 Windows 11 64비트
- 정식 설치된 OBS Studio 64비트
- .NET Framework 4.5 이상
- 인터넷 연결 및 설치 시 관리자 권한
- 각 플러그인의 추가 요구 사항은 위 사용 설명서 참고

**LiveEditor 0.4.0 이상을 선택하려면 OBS Studio 33.0.0 이상이 필요합니다.** 프로그램 시작 시 OBS 버전을 확인하며, OBS 33 미만이거나 버전을 확인할 수 없으면 LiveEditor 체크박스를 해제하고 비활성화합니다. 상태는 **사용 불가**로 표시하고 설명 아래에 필요한 OBS 버전과 현재 확인한 버전을 안내합니다. Event와 Ping의 선택에는 이 제한을 적용하지 않습니다. OBS를 업데이트했다면 통합 설치 프로그램을 다시 실행해 주세요.

현재 통합 설치 프로그램은 **포터블 OBS와 OBS 폴더 수동 선택을 지원하지 않습니다.**
해당 환경에서는 각 플러그인의 개별 배포판을 이용해 주세요.

## 다운로드

현재 통합 설치 프로그램 버전은 **1.1.12**입니다.
설치되는 각 플러그인의 버전은 실행 시 확인한 최신 정식 버전입니다.

- [Windows x64 설치 파일 바로 다운로드](https://github.com/TereBin/OBSChzzk/releases/download/v1.1.12/OBSChzzk-1.1.12-windows-x64-setup.exe)
- [최신 릴리스와 변경 사항 보기](https://github.com/TereBin/OBSChzzk/releases/latest)
- [SHA-256 체크섬 다운로드](https://github.com/TereBin/OBSChzzk/releases/download/v1.1.12/SHA256SUMS.txt)

설치 파일은 코드 서명되지 않아 Windows SmartScreen에 알 수 없는 게시자로 표시될 수 있습니다.
공식 릴리스에서 받은 파일인지 확인하고, 아래 명령의 결과를 릴리스의 `SHA256SUMS.txt`와 비교할 수 있습니다.

```powershell
Get-FileHash .\OBSChzzk-1.1.12-windows-x64-setup.exe -Algorithm SHA256
```

## 설치 및 업데이트

### 처음 설치

1. OBS Studio와 치지직 리모컨을 완전히 종료합니다.
2. 통합 설치 파일을 실행하고 관리자 권한 요청을 승인합니다.
3. 각 플러그인의 설명과 설치 버전·최신 버전을 확인합니다.
4. 사용할 플러그인만 체크하고 **선택한 플러그인 설치**를 누릅니다.
5. 선택한 플러그인들이 모두 **완료**로 표시되는지 확인합니다.
6. 완료 화면의 사용 설명서를 참고해 필요한 설정을 마칩니다.
7. OBS Studio를 직접 실행합니다.

선택한 파일을 모두 다운로드하고 검증한 다음 순서대로 설치합니다.
체크하지 않은 플러그인은 다운로드하거나 설치하지 않습니다.
이미 설치된 플러그인의 체크를 해제해도 해당 플러그인이 제거되지는 않습니다.

### 기존 플러그인 업데이트

통합 설치 프로그램을 다시 실행하고 **업데이트 가능**으로 표시된 플러그인을 선택해 설치합니다.
플러그인이 업데이트될 때마다 통합 설치 파일을 새로 받을 필요는 없습니다.

| 표시 | 의미 |
| --- | --- |
| 업데이트 가능 | 설치된 버전보다 새 정식 버전이 있음 |
| 최신 버전 | 설치된 버전과 최신 정식 버전이 같음 |
| 설치 버전이 더 높음 | 설치된 버전이 최신 정식 버전보다 높음 |
| 미설치 | 확인한 OBS 폴더에 해당 플러그인 DLL이 없음 |
| 버전 비교 불가 | DLL에 버전 정보가 없거나 비교할 수 없는 형식임 |

선택한 플러그인은 최신 정식 버전으로 재설치됩니다.
시험판이나 개발 버전을 사용하고 있다면 정식 버전으로 바뀔 수 있으므로 선택 전에 버전을 확인하세요.
프로그램을 오래 열어 두었다면 닫았다가 다시 실행해 최신 정보를 확인해 주세요.

### 통합 설치 프로그램 업데이트

**1.1.9부터** 실행할 때 이 저장소의 최신 정식 버전과 현재 프로그램 버전을 비교합니다.
새 버전이 있으면 다음 선택지가 표시됩니다. 플러그인 업데이트와는 별개의 기능입니다.

| 선택 | 동작 |
| --- | --- |
| 지금 설치 | 최신 EXE를 다운로드하고 SHA-256과 파일 버전을 검증한 뒤, 현재 EXE를 교체하고 다시 실행 |
| 다음 | 현재 버전으로 계속 사용하며 다음 실행 때 다시 알림 |
| 이 버전 건너뛰기 | 해당 최신 버전의 알림을 생략하고, 그보다 새로운 정식 버전이 나오면 다시 알림 |

창을 닫는 동작은 **다음**과 같습니다. 건너뛴 버전은 Windows 사용자별로 저장합니다.
확인에 실패하거나 시간이 초과되면 현재 프로그램으로 계속 사용할 수 있습니다.
교체·재실행에 실패하면 오류를 알리고 가능한 경우 기존 EXE를 복원합니다.
실행 파일 이름과 위치는 유지되므로 파일 이름의 버전 대신 프로그램 제목에 표시된 버전을 확인하세요.

1.1.8 이하에는 이 기능이 없으므로 이번 버전은 [최신 릴리스](https://github.com/TereBin/OBSChzzk/releases/latest)에서 직접 내려받아 실행해 주세요.

## 설치 후 설정

### OBSChzzkEvent

1. 완료 화면의 **Event 브라우저 확장 프로그램 설치 (Chrome 웹 스토어)** 링크를 클릭합니다.
2. [Chrome 웹 스토어](https://chromewebstore.google.com/detail/pakicliihbiimebagjgmmjkalfpejikc?hl=ko)에서 Chrome 또는 Edge에 확장 프로그램을 설치합니다. 기본 브라우저가 다른 브라우저라면 해당 주소를 Chrome/Edge에서 열어 주세요.
3. 기존 개발자 모드 설치본을 사용했다면 확장 프로그램 관리 화면에서 비활성화하거나 제거하고, 스토어 설치본만 사용합니다. 기존 폴더를 삭제할 필요는 없습니다.
4. OBS를 실행하고 치지직 리모컨을 다시 연 뒤 확장 프로그램에서 테스트 알림으로 연결을 확인합니다.

이미 스토어 설치본을 사용한다면 다시 설치하지 않아도 됩니다. Event 0.6.3부터 플러그인 설치 파일에는 확장이 동봉되지 않습니다.
확장은 브라우저가 자동으로 업데이트하고, OBS 플러그인은 통합 설치 프로그램 등으로 직접 업데이트합니다. 호환되는 조합이라면 두 버전 번호를 맞출 필요는 없습니다.
OBS에서 **치지직 팔로우 알림** 소스를 추가한 뒤 [Event 사용 설명서](https://github.com/TereBin/OBSChzzkEvent-Releases#readme)에 따라 테스트합니다.

### OBSChzzkLiveEditor

OBS의 **도크 > OBSChzzkLiveEditor**를 열고 치지직 계정으로 로그인합니다.
제목·카테고리·태그 변경 방법은 [LiveEditor 사용 설명서](https://github.com/TereBin/OBSChzzkLiveEditor-Releases#readme)를 참고하세요.

### OBSChzzkPing

OBS의 **도구 > OBSChzzkPing 설정**에서 치지직 채널과 Discord·X 알림을 설정합니다.
연결과 테스트 방법은 [Ping 사용 설명서](https://github.com/TereBin/OBSChzzkPing-Release#readme)를 참고하세요.

## 제거

통합 설치 프로그램 자체는 별도의 상주 프로그램을 설치하지 않습니다. 필요하지 않으면 내려받은 EXE를 삭제하면 됩니다.
설치한 플러그인은 OBS를 종료한 뒤 Windows의 **설정 > 앱 > 설치된 앱**에서 각각 제거합니다.
Event 브라우저 확장 프로그램은 Chrome/Edge에서도 별도로 제거해 주세요.
자세한 제거 방법은 각 플러그인의 사용 설명서를 참고하세요.

## 문제 해결

### OBS Studio를 찾지 못함

- **확인:** 기본 설치라면 `C:\Program Files\obs-studio\bin\64bit\obs64.exe`가 있는지 확인합니다.
- **해결:** 64비트 OBS Studio를 정식 설치합니다. 포터블 OBS나 자동 탐색이 되지 않는 환경에서는 개별 플러그인 설치 프로그램을 이용하세요.

### OBS가 실행 중이라는 안내가 표시됨

- **확인:** 작업 표시줄과 시스템 트레이에 OBS가 남아 있는지 확인합니다.
- **해결:** 작업을 저장하고 OBS를 완전히 종료한 뒤 다시 설치합니다. 설치 중에는 OBS를 실행하지 마세요.

### 최신 버전을 확인하지 못하거나 다운로드가 실패함

- **확인:** 인터넷 연결과 각 플러그인의 GitHub 릴리스 페이지에 접근할 수 있는지 확인합니다.
- **해결:** 프로그램을 다시 실행합니다. GitHub API 요청 제한(403·429)이 발생하면 공식 릴리스 페이지와 체크섬 파일로 자동 전환합니다. 계속 실패하면 해당 플러그인의 개별 배포판을 이용하고 오류를 알려 주세요.

### 설치됐는데 버전 정보가 없거나 미설치로 표시됨

- **확인:** 오래된 플러그인 DLL에는 Windows 버전 정보가 없을 수 있습니다.
- **해결:** 해당 플러그인을 최신 버전으로 설치한 뒤 통합 설치 프로그램을 다시 실행합니다. 버전 정보를 읽지 못한 것만으로 설치 실패를 의미하지는 않습니다.

LiveEditor 0.4.0부터 기본 설치 위치는 `%ProgramData%\obs-studio\plugins\OBSChzzkLiveEditor`입니다. 통합 설치 프로그램 1.1.11부터 이 위치에서 버전을 읽고 설치 결과를 검증하며, 이전 OBS 폴더의 설치본도 인식합니다. 1.1.10 이하에서 정상 설치 후 실패로 표시된다면 최신 통합 설치 프로그램으로 업데이트하세요.

### 일부 플러그인만 완료되고 나머지는 실패·중단됨으로 표시됨

- **확인:** **실패**로 표시된 플러그인과 하단 오류 메시지를 확인합니다. 이후 진행하지 못한 플러그인은 **중단됨**으로 표시됩니다.
- **해결:** 완료된 플러그인은 그대로 유지됩니다. 오류를 해결한 뒤 필요한 플러그인만 선택해 다시 설치하세요. 전체 설치를 되돌리는 기능은 없습니다.

### Event 확장 프로그램을 찾지 못하거나 알림이 작동하지 않음

- **확인:** Event 설치가 완료됐는지, Chrome/Edge에 웹 스토어 확장이 활성화돼 있는지 확인합니다. 0.6.3부터 확장 폴더가 동봉되지 않는 것은 정상입니다.
- **해결:** 위 웹 스토어 링크에서 확장을 설치하고 기존 개발자 모드 설치본은 비활성화하거나 제거합니다. OBS와 치지직 리모컨을 다시 열고 테스트하세요. 이후 문제는 [Event 문제 해결](https://github.com/TereBin/OBSChzzkEvent-Releases#문제-해결)을 참고하세요.

### 설치 로그 확인

아래 폴더에 실행별 설치 로그와 선택한 릴리스 정보가 저장됩니다. 파일 탐색기 주소창에 붙여 넣어 열 수 있습니다.

```text
%LOCALAPPDATA%\OBSChzzk\Logs
```

## 보안과 소스 코드

통합 설치 프로그램은 각 플러그인의 공식 GitHub 배포 저장소에서 설치 EXE를 내려받습니다.
다운로드한 파일의 SHA-256을 검증하며, 확인에 실패하면 설치하지 않습니다.
치지직 로그인이나 Discord 연결 정보는 통합 설치 프로그램에서 입력받지 않습니다.

소스 코드는 이 저장소에서 함께 제공합니다. 빌드와 검증 방법은 아래 개발자 안내를 참고하세요.
각 플러그인의 소스 코드와 라이선스는 해당 배포 저장소의 안내를 따릅니다.

<details>
<summary>개발자용 빌드 및 검증 방법</summary>

Windows 기본 .NET Framework C# 컴파일러를 사용합니다. 빌드 자체에는 네트워크가 필요하지 않습니다.

```powershell
./build.ps1
./test.ps1
# 최신 릴리스 조회·다운로드·해시 검증만 수행하며 실제 설치하지 않습니다.
./test.ps1 -Network
```

빌드 결과는 `dist` 폴더에 생성됩니다.
공식 저장소의 이름, 배포 파일 이름 규칙 또는 설치 프로그램의 명령줄 방식이 바뀌면 소스 수정이 필요할 수 있습니다.

</details>

## 문제 보고

통합 설치 프로그램의 오류와 기능 제안은 [OBSChzzk Issues](https://github.com/TereBin/OBSChzzk/issues)에 남겨 주세요.
설치 프로그램 버전, 선택한 플러그인, 오류 메시지와 관련 설치 로그를 함께 알려 주시면 확인에 도움이 됩니다.
로그를 첨부하기 전 사용자 이름이나 개인 경로 등 공개하고 싶지 않은 정보가 있는지 확인해 주세요.

설치 후 플러그인 기능에 관한 문제는 각 플러그인의 사용 설명서에 있는 문의 경로를 이용해 주세요.
공개 이슈 작성이 어렵다면 [Discord에서 TereBin에게 문의](https://discordapp.com/users/537256771501424640)할 수 있습니다.
